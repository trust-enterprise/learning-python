# Expense Tracker

A simple Python expense tracker that saves expenses to a text file.

## Features

- Add expense
- View expenses
- View total expense
- Save expenses permanently in a file

## Concepts Learned

- Classes and Objects
- Instance Methods
- Class Methods
- `__str__()` Magic Method
- Creating objects from file data

## Example

Food,100
Travel,200
Books,300
Total Expense: INR 600

## Built With

Python 3
